# Phase 45 Accessibility Checklist

- [ ] Every important action has an accessible name.
- [ ] Every form field has a visible/semantic label.
- [ ] Images have meaningful alt text or are explicitly decorative.
- [ ] Keyboard focus is visible.
- [ ] Modal/dialog focus is managed correctly.
- [ ] Escape closes dismissible overlays where appropriate.
- [ ] Text remains readable at 200% zoom.
- [ ] No important information depends only on color.
- [ ] Touch targets are comfortable on mobile.
- [ ] Reduced motion is respected.
- [ ] Error messages are understandable and announced appropriately.
- [ ] Login, payment, assignment and test flows are keyboard/screen-reader usable.
