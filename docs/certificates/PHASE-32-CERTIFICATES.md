# VATTAMS Academy Phase 32 — Certificates & QR Verification

## Certificate system
- Unique VATTAMS certificate number
- Course / competition / achievement / completion certificate types
- Issue date and completion date
- Score, percentage and grade
- Issuer is VATTAMS Academy
- Issued / revoked status

## Verification
Every certificate receives a unique verification token and verification URL.

QR code generation can point to:
`https://vattams.net/#/certificate/verify/<verification-token>`

The public verification endpoint exposes only certificate verification information. It does not expose the student's private account details.

## Important
VATTAMS Academy certificates are platform-issued certificates. Do not claim government, university, board or third-party accreditation unless separately and officially obtained.
