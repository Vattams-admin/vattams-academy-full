# VATTAMS Academy Phase 26 — Student Progress & Learning Analytics

## Student view

Students can see:
- Overall progress indicator
- Attendance percentage
- Class completion
- Assignment submissions
- Test attempts and average percentage
- Competition attempts
- Certificates issued
- 30-day progress history

## Admin view

Admin can:
- Look up a student by Student ID
- View current progress
- View 30-day history
- Refresh the student's progress snapshot

## Guardian compatibility

Phase 27 remains in the project. Guardian access is still controlled by the existing share permissions. Phase 26 does not open a new public route or bypass Guardian permissions.

## Safety

Progress is an informational learning indicator. It does not replace official course results or certificate decisions.

The snapshot table is additive. Existing transactional tables are read only; no existing Tuition data is deleted or rewritten.
