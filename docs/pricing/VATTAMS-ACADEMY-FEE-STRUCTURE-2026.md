## Tutor payment — HOURLY BASIS

VATTAMS Academy will use a **fixed hourly tutor payout model** for the launch.

| Specialist / Advanced subject | ₹500–₹800/hour |

### Important payout rules

1. The configured amount is for a completed **60-minute teaching session**.
2. If the actual teaching duration is different, payout is prorated by approved minutes.
3. Example: ₹300/hour × 45 minutes = ₹225.
4. Student no-show, tutor no-show, cancelled class and rescheduled class must follow separate attendance/cancellation rules.
5. Tutor payout should be generated only for an eligible/completed class.
6. The Admin can configure the hourly rate by category/level.
7. Do not call this a monthly salary unless the tutor is actually an employee under a separate employment agreement.
8. Tutor payout should be recorded independently from the student's billed fee.

## Group class payout

For group classes, the tutor payout should remain hourly rather than per student.

Example:
- 60-minute batch
- 10 students
- Student fee ₹1,299/month for 8 classes
- Tutor payout ₹350/hour
- 8 completed classes → ₹2,800 tutor payout for that batch/month

This keeps tutor compensation predictable while VATTAMS benefits from batch economics.
