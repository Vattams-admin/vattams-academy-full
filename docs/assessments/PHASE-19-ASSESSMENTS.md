# VATTAMS Academy Phase 19 — Assignments + Tests

## Assignments

- Tutor/Admin creates and publishes assignments.
- Student must have an active course enrollment.
- Student submits text (file URL support is stored for future material upload integration).
- Tutor/Admin reviews and awards marks.
- Feedback and review status are stored.
- Late submissions are identified from the due date.

## Tests

Supported question types:
- MCQ
- True/False
- Short Answer

Test features:
- Configurable duration
- Configurable maximum attempts
- Pass percentage
- Auto-grading for MCQ and True/False
- Short answers remain available for later manual review
- Attempt history
- Score, percentage and pass/fail result
- Time-expiry protection
- Server-side enrollment check

## Security

- Only active enrolled students can start/submit protected tests.
- Question correct answers are never sent to the student during test start.
- Correct answers remain server-side.
- Admin/tutor assessment management is authenticated.
- Existing Tuition data is preserved.
- No destructive database changes.

## Future integration

The result data is ready to feed:
- Student progress
- Reports
- Competition rankings
- Certificates
- Tutor performance
