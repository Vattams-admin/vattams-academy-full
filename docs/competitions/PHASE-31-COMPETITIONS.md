# VATTAMS Academy Phase 31 — Competitions, Leaderboards & Results

## Student
- Browse published competitions
- Register
- Start within the configured schedule
- Complete timed questions
- Submit
- View leaderboard
- Receive Academy performance award labels

## Tutor
- Competition creation foundation
- Category and competition type
- Schedule
- Participant limit
- Question creation through the competition service

## Admin
- Competition schedule and management foundation

## Fairness
- One entry per student per competition
- Server-side timing check
- Server-side grading for objective questions
- Rank calculated from recorded results
- Short-answer questions are not automatically awarded marks
- Public UI does not expose student identity details in the leaderboard

Awards are Academy-created performance labels only. No external accreditation is implied.
