# VATTAMS Academy Phase 30 — Assignments & Tests

## Assignments

Students can:
- View published assignments
- See instructions and due dates
- Submit text responses
- Update submissions before review
- See reviewed score and tutor feedback

Tutors can:
- Create and publish assignments
- Set maximum score and due date
- Review submissions
- Record score and feedback

## Tests

Students can:
- View available tests
- Start an attempt
- Answer MCQ, true/false or short-answer questions
- Submit the attempt
- Receive pass/fail status and percentage

Tutors can:
- Create tests
- Configure duration, attempts and pass percentage
- Add questions

## Assessment safety

Short-answer questions are intentionally not auto-scored in this phase; they remain available for future manual review.

Existing Tuition data remains untouched.
No destructive database changes.
