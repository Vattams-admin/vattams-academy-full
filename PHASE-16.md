- Class 6–8: ₹399/session
- Class 9–10: ₹499/session
- Class 11–12: ₹599/session
- Foundation: ₹499–₹699
- Competitive Foundation: ₹599–₹799
- JEE/NEET Foundation: ₹799

- IELTS/TOEFL/PTE: ₹699–₹1,199
- Public Speaking: ₹499–₹799

## Tutor payout — hourly

- Primary: ₹200/hour
- Middle: ₹250/hour
- Secondary: ₹300/hour
- Senior Secondary: ₹350/hour
- Foundation/Olympiad: ₹350/hour
- Competitive Foundation: ₹400/hour
- JEE/NEET Foundation: ₹500/hour
- Coding: ₹450/hour
- AI/Data Science: ₹600/hour
- International English: ₹450/hour
- Public Speaking: ₹350/hour
- Specialist: ₹500–₹800/hour

### Calculation

A 60-minute completed session receives the configured hourly payout.

For shorter approved sessions:

`payout = hourly_rate × approved_minutes / 60`

Example:
₹300/hour × 45 minutes = ₹225.

## Tutor joining fee

₹499 one-time Tutor Registration & Verification Fee.

It must not be marketed as payment for guaranteed students, guaranteed income, employment or guaranteed approval.

## Group classes

Tutor payout remains hourly, not per student.

Example:
8 completed one-hour classes × ₹350/hour = ₹2,800 tutor payout for that batch/month.

## Existing tutor workflow

Existing tutor registration, UTR, payment and approval logic is preserved.
No destructive database changes.
