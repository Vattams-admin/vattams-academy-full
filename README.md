# VATTAMS Academy

**Learn. Practice. Achieve.**

VATTAMS Academy is a mobile-first online education platform served from **https://vattams.net**.

## Product roles

- Student
- Tutor
- Tuition Admin

## Learning scope

Academic subjects, foundation programs, communication skills, coding and AI, competitive exams, international exam preparation, competitions and professional digital certificates.

## Existing Tuition foundation

The project preserves the existing Tuition data and registration workflows, including tutor registration/payment/UTR/approval and student registration.

## Development

```bash
npm install
npm run build
npm run dev
```

Production launch target: **5 September 2026**.
