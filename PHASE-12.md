# VATTAMS Academy Phase 12

Competitions and leaderboards.

Features:
- Competition categories
- Admin/Tutor competition creation
- Admin publishing
- Student registration
- Timed competition structure
- Question-bank reuse
- Automatic scoring
- Rank
- Leaderboard
- Student competition results

Important:
- The competition certificate flag is stored but certificate issuance should remain controlled by Admin and connected to the existing Phase 11 certificate system after official winner/eligibility rules are defined.
- No external accreditation claim.
- Existing Tuition data is preserved.
